## What happened to the six sealed risks

The frozen-error brief predicted non-writable descriptors, lost enumerability, and incomplete
coverage of other Error subclasses. The implementation explicitly set `writable`, `enumerable`, and
`configurable`; exercised the subclass construction under a frozen prototype; and left the broader
classes unreachable from the affected task-runner realm. Post-run audit rated all three risks as
having no review value.

The agent-guardrails brief predicted a missing manual-chat-trigger ancestry case, a blank stored
`auto` label after option removal, and leakage of shared prompt options into non-Agent nodes. The
implementation used a separate dual-trigger helper with a direct test, kept the option present but
disabled, and gated the update to Agent v3.1+. These were reasonable implementation questions but
not findings; post-run audit rated all three decorative.

The dominant actual agent-guardrails defect was different: an existing option description made the
new nullish-coalescing hint unreachable. The base reviewer found it without the edge brief. This is
the core limitation exposed by the screen: the implementation-blind pass anchored on hypothetical
implementation shapes and did not discover the pre-existing consumer contract that the actual
implementation violated.

## Decision

Do not select confirmation cases and do not auto-compose `anticipate-edge-cases` into code review.
The strict verifier/assembler is a valid safety mechanism, but adding a costly mechanism that
reliably returns the base review is not useful by itself. Upfront exposure still exhibits the
attention-allocation failure the experiment was designed to detect.

If exploration continues, it should be a distinct experiment rather than another automatic
placement permutation:

1. Run the pre-registered human-sidecar study only if a real reviewer is available; measure useful
   probes, time, unsupported claims, and cognitive load on uncontaminated PRs.
2. Otherwise park composition and improve the standalone edge generator's contract/consumer
   discovery using new target-only behavioral cases. Do not tune on these two screening heads.
3. Reopen automatic composition only after the standalone artifact demonstrates source-valid lift
   on fresh cases. No current automatic or routing arm earned confirmation budget.
