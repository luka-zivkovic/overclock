## Iterations and falsification notes

The pilot found and corrected three boundary defects before acceptance:

1. The first positive run tried to open the bundled risk-lens file directly. Lens loading was moved
   behind the allowlisted inspector helper.
2. A later positive run abbreviated evidence SHAs. The output contract now requires the complete
   40-character analysis base in every citation.
3. Shell-variable prefixes and an unnecessary SHA-length check caused permission denials. The skill
   now requires direct helper invocations and trusts the helper's commit validation.
4. The first final-candidate negative run reached the right conclusion only after a repository
   tour. Mechanical changes now short-circuit before base resolution or any helper call.

One additional positive attempt produced a generic baseline answer because the prompt named the
Codex-facing `$skill` token without invoking Claude's namespaced slash command. It is excluded from
skill evidence and retained in generated artifacts as a harness-control failure.
