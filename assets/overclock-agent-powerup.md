# Overclock README artwork

Asset: `overclock-agent-powerup.png`

An AI agent powering up in a black-and-white manga illustration. Created with the built-in image generation tool in edit mode, using an earlier robot character study as the reference. The approved output is used without post-processing. This is editorial artwork, not a diagram of the software.

## Art direction

A confident AI agent in a full-body power-up stance, with clenched fists, a rising energy aura, and levitating stones. Simple black-and-white manga linework, inspired by Goku powering up.
