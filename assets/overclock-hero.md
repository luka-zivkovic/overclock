# Overclock README artwork

Asset: `overclock-hero.png`

Created with the built-in ImageGen tool in generation mode. The original PNG
is used without post-processing. The image is an editorial metaphor, not a
diagram of the software or a product screenshot.

## Prompt

Use case: stylized-concept.
Asset type: polished GitHub README hero banner for Overclock, a collection of reusable coding-agent skills.
Primary request: replace an austere black-and-white speed-dial diagram with a beautiful, memorable editorial illustration. Create a wide 3:1 composition, approximately 1536 by 512 pixels.
Subject: a beautifully crafted kinetic instrument, a central brushed-aluminum flywheel surrounded by three fine orbital rails, with a small set of ivory modular instruction cards smoothly feeding through it and emerging as an orderly luminous path. The image is a visual metaphor for accumulated know-how becoming reliable repeated work, not a technical schematic.
Style: refined industrial-design illustration with realistic materials and subtly surreal composition; sculptural, tactile, exceptionally crisp, restrained. Soft studio light catches machined edges and translucent blue glass. Deep midnight indigo background, warm ivory cards, a small warm amber glow in the central mechanism. Elegant negative space and an immediately legible silhouette at GitHub README width. Balanced central composition with the whole instrument comfortably inside the frame.
No text, letters, numbers, slogans, logos, watermarks, dashboard UI, robot faces, generic glowing microchip, or clutter. The README supplies the title separately. One finished banner image.
