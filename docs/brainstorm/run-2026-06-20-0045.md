## ai-client-context-sync — KILL
- **Verdict:** KILL
- **Moat axis:** tool-agnostic portability across AI clients, applied to the INSTRUCTION layer
  (CLAUDE.md <-> AGENTS.md <-> .cursorrules) rather than memory artifacts — the strongest-novelty
  candidate of the set.
- **Baseline-gap finding:** Duplicative on both halves at once. (1) Trivial-mechanism side:
  Claude Code native `@path` imports make CLAUDE.md a thin pointer (`@AGENTS.md` + Claude-only
  additions) to one shared source — exactly what the user's ONLY both-files repo
  (gumroad-store/.../agentship) already does in production, so divergence is structurally
  impossible and no reconciler is needed. Claude Code also natively reads AGENTS.md as a fallback,
  so AGENTS.md-only repos (balin, Kagawa) already receive the guidance. (2) Semantic side: merging
  two genuinely drifted prose docs is native LLM summarization (the candidate's own stated
  baseline). The defensible move (make non-Claude clients honor shared guidance) is unreachable —
  a Claude Code skill only executes inside Claude Code; its only lever is writing files, and the
  file-writing problem is already solved by @-import with zero skill.
- **Sim:** not run (KILLed at grounding).
- **Votes:** not cast.
- **Decisive reason:** Demand fails both prongs empirically — across ~18 local repos, ZERO carry
  two genuinely diverging files (the lone both-files repo uses @-import correctly = a solved case,
  evidence AGAINST a gap), and ZERO user-typed "sync these instruction files" requests exist (the
  90 "sync" hits are unrelated state/file-sync noise). Owned-by-mechanism + native-LLM-collapse,
  the pattern the ledger has KILLed 30+ times. Failed baseline-gap test.

- **Sim:** not run (KILLed at grounding).
- **Votes:** not cast.

  a live producer and a consumer — is moat-signal-unobtainable (version lives behind a running

- **Sim:** not run (KILLed at grounding).
- **Votes:** not cast.
- **Decisive reason:** After decontamination, ~3-4 genuine port-kill requests, all in ONE project
  (balin, itself a server-spawning product). Below the blast-radius bar; the kill is a trivial
  one-liner and the memory bit is small and redundant; no defensible mechanism. Genuinely new
  domain+modality, but fails creation-bar prongs 1 and 2.
