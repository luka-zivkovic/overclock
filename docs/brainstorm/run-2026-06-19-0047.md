## Run takeaways
- The divergence mandate was honored — these are genuinely fresh domains (design fidelity,
  config drift, spec-less API integration, mechanical rewrites) and fresh modalities (DO/transform,
  not remember). The baseline-gap test still judged "build nothing."
- Two failure shapes recurred. (a) **owned-by-deterministic-CLI + native-LLM-collapse**: every
  buildable core is owned by a mature CLI ecosystem the agent already shells out to (impeccable,
  envscan/dotenv-audit, quicktype/openapi-*/curl-to-json-schema, ast-grep), and the residual is
  base-model reasoning — so an LLM-grep reimplementation is measurably WORSE, not better.
  (b) **moat-signal-unobtainable**: env-contract-sync's defensible third leg (deploy-side secrets)
  lives behind an external API the file-editing skill cannot deterministically enumerate.
- Prong-1 held the line again: after filtering type:user messages and removing this brainstorm's
  own prompt contamination, design-port = 2 real requests (its load-bearing "live failure" was an
  agent self-audit, i.e. baseline success); env-contract-sync = 1 arc in 1 product; the other two
  = literal zero. The "false premise" trap also recurred — design-port's entire moat rested on a
  claim about impeccable that grounding proved FALSE.
