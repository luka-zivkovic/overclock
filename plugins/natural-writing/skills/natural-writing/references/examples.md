# Before / after pairs

Few-shot examples for the natural-writing rules. Each shows a violation (✗) and a natural rewrite (✓).
Use them as a calibration reference when drafting or revising.

**Base source:** curated and de-conflicted from the [`mine-writing-rules`](https://github.com/shreyashankar/mine-writing-rules)
corpus (880 rules distilled from 63 style guides), with repository-specific pairs added as rules
evolved. This is a fixed snapshot, not a runtime dependency. The pairs illustrate the fallback
house style, not universal laws; a project style guide or recognizable authorial choice may differ.

## Plain words over showy ones (rules 2, 6)

- ✗ Subsequent to the initiation of treatment, we endeavoured to ameliorate the deleterious phenomenon via expeditious interventions.
- ✓ After treatment began, we tried to reduce the harm quickly.

- ✗ In the event that we experience a reduction in funding, we will make an adjustment to the schedule.
- ✓ If funding drops, we will adjust the schedule.

## Kill AI-tell vocabulary and buzzwords (rule 2)

- ✗ We leveraged a novel paradigm to synergize cross-functional knowledge transfer and facilitate deliverables.
- ✓ We used a new approach so the teams could share knowledge and finish the work.

- ✗ We leverage our robust data platform and synergize it with your workflow tools to deliver a
  massive boost in reporting speed.
- ✓ We combine our data platform with your workflow tools to cut reporting time.

- ✗ Here's the magic: Atlas seamlessly unlocks better collaboration and empowers every team.
- ✓ Atlas keeps approval history beside each change, so teams can see who approved it.

## Remove manufactured punch and closure (rule 4)

- ✗ This isn't about adding another tool. It's about transforming how your team works.
- ✓ The tool keeps approval history beside each change.

- ✗ The cache expires entries after ten minutes. In short: freshness is everything.
- ✓ The cache expires entries after ten minutes.

- ✗ The worker retries failed uploads three times, which is exactly what makes it reliable.
- ✓ The worker retries failed uploads three times.

- ✓ This isn't a retry. The server accepted the first request; only the response was lost.
  [Keep a contrast when it carries a distinction the reader needs.]

## Cut filler, hedges, and intensifiers (rules 3, 8)

- ✗ However, it is important to note that, in many cases, the results that we obtained were, surprisingly, significant.
- ✓ The results were significant in many cases.

- ✗ This is an extremely important and highly significant finding with very broad implications.
- ✓ This is an important finding with broad implications. [Name the supported implications when
  the source supplies them.]

- ✗ It is important to note that you should make sure to save your work before exiting.
- ✓ Save your work before exiting.

- ✗ Each and every researcher must submit a full and complete report.
- ✓ Every researcher must submit a complete report.

## Lead with the claim, hedge after (rule 8)

- ✗ While the evidence is mixed and context-dependent, there may be some reason to think that, in certain situations, early feedback could plausibly improve outcomes.
- ✓ Early feedback may improve outcomes in some settings. The evidence is mixed, and the next
  section explains where the effect weakens.

- ✗ You can add a product description to help customers.
- ✓ Add a product description to help customers.

## Strong verbs — don't bury the action (rule 10)

- ✗ There was a failure on the part of the committee to reach a decision, so they conducted an investigation of the compound.
- ✓ The committee failed to decide, so they investigated the compound.

- ✗ Configuring the runner involves setting environment variables.
- ✓ To configure the runner, set the environment variables.

## Concrete over vague (rule 7)

- ✗ Ongoing socioeconomic challenges create adverse outcomes for vulnerable populations.
- ✓ Economic hardship harms vulnerable people. [Name the supported harms when the source supplies
  them.]

- ✗ The unemployment situation is a function of the wage structure in the current time frame.
- ✓ Current wage structures affect unemployment.

- ✗ We will follow up soon. Please contact our office.
- ✓ We will follow up soon. Contact our office if you need an update. [Add a date and contact
  method when they are known.]

## Active voice — name who did it (rule 11)

- ✗ Mistakes were made and a decision was taken to discontinue the program.
- ✓ Mistakes occurred, and the program was discontinued. The source does not identify who made
  either decision.

- ✗ The data were analyzed, the results were recorded, and the conclusions were drawn by the research team.
- ✓ The research team analyzed the data, recorded the results, and drew the conclusions.

## Vary the rhythm (rule 5)

- ✗ The sun came out and the ice melted and the streets flooded and traffic stopped.
- ✓ When the sun came out, the ice melted. Streets flooded and traffic halted.

## Don't bold for decoration (rule 12)

- ✗ **First,** set up the project. **Then,** install the dependencies. **Finally,** run the build.
- ✓ First set up the project, then install the dependencies, then run the build.

- ✓ (bold as a real header is fine) **Live feedback loop.** Poll the file and react as events arrive.
